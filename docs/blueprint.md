# **App Name**: MedNotes Navigator

## Core Features:

- File Structure Display: Display the file structure (main sections and subsections) in a navigable tree view.
- Quick Navigation: Implement quick navigation between files and sections using large, easily accessible buttons.
- Global File Search: Enable full-text search across all PDF files with one-click access to the relevant file.
- Embedded PDF Reader: Display PDFs in an embedded reader for easy viewing.
- AI Summary Generator: Summarize key points of selected files using a generative AI tool.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6), to evoke calmness, professionalism, and trustworthiness in medical context.
- Background color: Very light blue (#F0F8FF). This subtle tone maintains focus on the content without causing distraction.
- Accent color: Soft teal (#70CBC0). Positioned approximately 30 degrees 'left' on the color wheel, it differentiates calls to action, while maintaining a sense of harmony with the primary color.
- Body and headline font: 'PT Sans' (sans-serif), chosen for its modern yet warm feel, suitable for both headlines and body text. 
- Use simple, clear icons to represent main sections and subsections, enhancing usability and visual appeal.
- Prioritize a clean, spacious layout with a prominent search bar and easily accessible navigation controls.
- Subtle transitions and animations on navigation actions to provide a smooth and intuitive user experience.
